# Modern Vulkan on LWJGL

Constref's/nickenchev's excellent modern Vulkan tutorial loosely translated from C++ into Java.

The original can be found here: https://github.com/nickenchev/modern-vulkan

## Notes

Clone with: `git clone --recurse-submodules -j8 git://github.com/basdxz/ModernVulkanLwjgl.git`
I included the Khronos sample gltfs as a git submodule.

So far only lesson 1 and 2 have been 'finished', the master branch was based on the work I would assume is planned for lesson 3.
